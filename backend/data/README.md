# Portfolio data

These JSON files are the project's source of truth.

- `profile.json` — personal profile
- `skills.json` — skills
- `experiences.json` — career experience
- `projects.json` — portfolio projects
- `contact-messages.json` — messages submitted through the contact form
- `images/` — project/profile images

You can edit these files manually. The API also updates the project and contact-message files through the repository layer.
